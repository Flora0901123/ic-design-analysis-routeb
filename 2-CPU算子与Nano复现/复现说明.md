# CPU与Nano复现说明（2026-10-29更新）

在WSL2 Ubuntu 24.04中进入本交付根目录。所有运行仅操作交付内的student-mini-v1-cpu-gpu副本。

1. `bash setup.sh` 准备开发环境；该步骤不代表正式合规。参考包完整性独立执行 `python3 reproduce.py verify-reference`，目前已有BIOS Makefile差异，须保留审计失败。
2. `python3 reproduce.py doctor` 检查环境。
3. `python3 reproduce.py cpu --limit 1000 --variant baseline` 完整基线运行。
4. `python3 reproduce.py cpu --limit 1000 --variant topk` 完整排序候选回归。
5. `student-mini-v1-cpu-gpu/sources/.venv/bin/python nano.py --variant baseline --repeat 1` Nano基线。
6. 将variant分别改成topk、rne、combined完成消融；最终同问题重复实验使用 `--repeat 100`。每组均独立保存，不读取旧转录冒充新运行。

每次结果位于8-本轮实验，检查status.json、console日志和官方numeric报告。早期baseline运行的初版校验器误检查P2 selected列表，复核结果以reviewed-status.json与官方报告为准，初版输出保留。

Nano计数覆盖mini_native_generate，包含EOS，不包含启动、主机分词与输入搬运；不能称为主机收到输入到界面显示文字的全部墙钟。每token解码取首token后相邻token周期差的均值，原始间隔全部保存。

组件RNE检查与主机1000条预检是补充数值证据，不能替代RTL、协议、物理与资源门槛。新安装环境仍需实际完整重跑后才能称为干净环境复现；异机测试另行执行。
