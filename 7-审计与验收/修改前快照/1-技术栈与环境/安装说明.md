# 技术栈与环境（WSL2 Ubuntu-24.04）

本机实测版本快照见 `toolchain-snapshot.json`。以下为从零搭建命令。

## 一、系统工具（root）

```bash
wsl -d Ubuntu-24.04 -u root -- bash -c '
export DEBIAN_FRONTEND=noninteractive
apt-get update
apt-get install -y --no-install-recommends \
  build-essential cmake ninja-build pkg-config bison flex gawk \
  python3-pip python3-venv git curl ca-certificates \
  verilator binutils-riscv64-unknown-elf gcc-riscv64-unknown-elf \
  openjdk-11-jdk-headless openjdk-17-jdk-headless \
  libevent-dev libjson-c-dev zlib1g-dev libreadline-dev
'
```

## 二、Python venv（数值 + LiteX 生态）

```bash
cd student-mini-v1-cpu-gpu/sources
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt        # numpy/cocotb/pytest/ml-dtypes
.venv/bin/python -m pip install \
  litex migen litedram liteeth liteiclink litescope meson \
  pythondata-cpu-vexriscv pythondata-software-picolibc \
  pythondata-software-compiler-rt pythondata-misc-tapcfg
```

## 三、VexRiscv RTL（绕过 sbt 生成）

冻结的 `VexRiscv_Full_4k.v` 需 sbt+Scala2.11 生成（与 Java17/sbt1.10 不兼容）。
改用 `pythondata_cpu_vexriscv` 预生成的 `VexRiscv_Full.v`（`GenCoreDefault` 默认即 iCache/dCache=4096）：

```bash
.venv/bin/python -c '
import pythondata_cpu_vexriscv as pd, shutil
from pathlib import Path
src = Path(pd.__file__).parent / "verilog" / "VexRiscv_Full.v"
dst = Path("build/vexriscv-profiles"); dst.mkdir(parents=True, exist_ok=True)
shutil.copyfile(src, dst / "VexRiscv_Full_4k.v")
'
```

## 五、版本要点

- Verilator 5.020（apt 最高；课程要求 5.040，但 CPU B0 非 nano 路径不校验版本）
- LiteX 2024.12（`toolchain.lock.json` 缺失，用 best-effort 版本，`soc.py` API 实测兼容）
- Java 17（sbt 运行）＋ Java 11（备用，Scala2.11 仍不兼容，故弃用 sbt 生成）
