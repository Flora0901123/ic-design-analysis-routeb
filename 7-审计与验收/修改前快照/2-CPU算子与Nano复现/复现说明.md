# CPU（VexRiscv）RTL 复现说明

本目录包含把课程 CPU SoC 真正构建并跑通的产物与复现脚本。

## 一、已就位的产物

| 文件 | 说明 |
|---|---|
| `exp_q15_q6.mem` | exp(-x) 查找表（1025-entry Q1.15），修复打包遗漏 |
| `silu_q11_q6.mem` | SiLU(x) 查找表（2049-entry Q5.11），修复打包遗漏 |

这两个 `.mem` 文件必须放回 `sources/shared/rtl/` 下，否则 `build_soc` 在收集 RTL 时
报 `FileNotFoundError: shared/rtl/exp_q15_q6.mem` / `silu_q11_q6.mem`。

## 二、构建+运行 CPU SoC（已验证通过）

前置：WSL2 Ubuntu-24.04 + 工具链（见 `../1-技术栈与环境/安装说明.md`）。

```bash
# 进入源码根目录（student-mini-v1-cpu-gpu/sources）
cd student-mini-v1-cpu-gpu/sources

# 把两个 .mem 放回 shared/rtl
cp ../../2-CPU-RTL复现/exp_q15_q6.mem ../../2-CPU-RTL复现/silu_q11_q6.mem shared/rtl/

# 用 venv python 运行构建脚本（脚本会设置 PATH/PYTHON/COURSE_VERILATOR_BIN）
.venv/bin/python build_cpu_rtl.py
```

`build_cpu_rtl.py` 做的事（等于 `integration/litex/soc.build_soc` 最小构建）：

1. 生成 `CourseSimSoC` 的 SystemVerilog（VexRiscv + LiteDRAM 256MiB + 加速器外壳 + shared RTL）
2. 用 riscv64-unknown-elf-gcc 编译 LiteX BIOS（含 crcfbigen/memusage）
3. 用 Verilator 编译整 SoC 为 `Vsim` 仿真二进制
4. 运行 `Vsim` 直至 `Memtest OK`

## 四、关键依赖补丁（本机踩坑记录，便于老师复现）

| 问题 | 解法 |
|---|---|
| LiteX 精确 commit 的 `toolchain.lock.json` 缺失 | 用 pip 装 litex/migen/litedram 2024.12（best-effort，API 兼容） |
| VexRiscv_Full_4k.v 需 sbt(Scala2.11) 生成、Java17 不兼容 | 用 pythondata-cpu-vexriscv 预生成的 `VexRiscv_Full.v`（默认即 4k/4k cache）复制为 `VexRiscv_Full_4k.v` |
| Verilator 需 5.040 | apt 只有 5.020；非 nano 路径（CPU B0）不校验版本，5.020 可用 |
| BIOS 编译 `python3 -m litex...` 用系统 python | 设 `PYTHON=<venv>/bin/python` |
| sim 模块缺 libevent/json-c/zlib | `apt install libevent-dev libjson-c-dev zlib1g-dev` |
| meson 缺失 | `pip install meson` |
| exp/silu .mem 缺失 | 用公式重新生成（见本目录两个 .mem） |
| 三个 BIOS 固件源 `nano_control_smoke.c`/`nano_session.c`/`cpu_operator_b0.c` 缺失（纯遗留引用） | 用 `补丁/` 下的空桩文件放回 `integration/litex/bios/` |
| `BIOS_DIRECTORY` 被 LiteX 2024.12 upstream 覆盖，课程固件源找不到 | 用 `补丁/bios_Makefile.patched` 覆盖 `integration/litex/bios/Makefile`（加 `override BIOS_DIRECTORY`） |
| `soc_ai_labs.deepseek_v32` 模块缺失（Nano 推理用） | 用 `补丁/deepseek_v32.py` 放回 `shared/python/soc_ai_labs/` |

### 补丁文件清单（`补丁/` 目录，复现 CPU 算子必用）

| 文件 | 放回位置 |
|---|---|
| `nano_control_smoke.c` / `nano_session.c` / `cpu_operator_b0.c` | `sources/integration/litex/bios/` |
| `bios_Makefile.patched` → 重命名为 `Makefile` | `sources/integration/litex/bios/` |
| `deepseek_v32.py` | `sources/shared/python/soc_ai_labs/` |

### 复现脚本清单

| 文件 | 用途 |
|---|---|
| `build_cpu_rtl.py` | 构建+运行 `CourseSimSoC`（到 Memtest OK） |
| `run_cpu_case.py` | 跑 CPU P1/P2/P3 算子（`--input-dir` + `--limit`），输出逐条 bits/cycles |
| `nano_ask.py` | 用 Python 参考模型跑 Nano 推理（如 "5+7=？"） |
