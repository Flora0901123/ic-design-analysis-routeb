## 当前支持的复现入口

在WSL2 Ubuntu中、RouteB根目录执行：

```bash
bash setup.sh
python3 reproduce.py verify-reference
student-mini-v1-cpu-gpu/sources/.venv/bin/python reproduce.py cpu --limit 1000
```

这些命令覆盖环境准备、离线校验及CPU运行，**不是GPU全部实验的统一一键验收**。`setup.sh`会安装依赖，运行前应阅读[环境安装说明](../1-技术栈与环境/安装说明.md)。

Nano入口为`nano.py`（baseline/topk/rne/combined、repeat）；GPU与完整回归实验脚本位于`7-审计与验收`和`9-GPU复现`。部分为绑定现有本机实验目录的一次性脚本，不承诺直接搬到新机器即全部通过。保留脚本正是为了展示过程和便于后续整理统一入口。

本次仅做文件整理和证据完整性检查，不把已有结果冒充再次重跑。第二台电脑暂不可用，未宣称异机复现通过。
