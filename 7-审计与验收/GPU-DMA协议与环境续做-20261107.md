# GPU DMA、适配器协议与锁定环境续做记录（2026-11-07）

本记录为当前工作包的增量证据入口。当前仍 HOLD；不预填分数，不宣称整机 DMA 或物理验收完成。

## 已完成的修正与检查

1. **整机 DMA 缺件预检**：三例 P1/P2/P3-MINI-30 × seed1–10，共30条。逐项保留冻结协议、BUS_ERROR 期望、error-response / no-output-commit / no-new-payload-dma-after-error 事件要求。实际全部 NOT_EXECUTED，没有用适配器结果补成整机通过。
   - 证据：`8-本轮实验/GPU整机DMA预检-20261107/completion.json`
   - 缺件：映射 `project-banked.v`、`staged-openram-banked-manifest.json`、对应 SRAM 模型、`assemble_student_mini_gpu_counters.py`。
2. **修复状态地址的工具展开差异**：Yosys0.33 中，原 `localparam logic [ADDR_WIDTH-1:0] STATUS_ADDR = '1` 展开出的比较常量只有1位；12位接口要求 FFF。开发源码改成 `{ADDR_WIDTH{1'b1}}`，保留原始源码、反例、前后展开JSON。原始教师参考包没有修改。
   - 证据：`8-本轮实验/GPU地址常量兼容修正-20261107/`。
   - 开发源码：`student-mini-v1-cpu-gpu/sources/integration/student-mini/gpu_status_command_adapter.sv`。
3. **全位宽局部安全归纳证明通过**：真实 memory adapter 使用512位data / 26位addr / 10位tag / 64位mask；命令接口12位addr / 32位data。内存契约归纳长度2、命令契约长度3成功，基例也证明。初始采样复位有效，其余输入无额外约束；检查请求/响应握手捕获与背压稳定、同步复位冲刷、故障粘滞和错误优先于清除、忙START拒绝、写/读/非法命令响应、FFF状态快照与响应保持等。
   - 证据：`8-本轮实验/GPU适配器局部契约-20261107/completion.json` 及两个 `proof.log`。
   - 早期8步BMC超时及地址常量反例保留在该目录 `initial-attempt/` 和 `command-diagnosis/`。
   - **边界**：单个接口适配器的所列局部安全性质；没有GPU核、SRAM、无界活性、整机无新payload DMA/输出提交性质。原始组合harness的32步/覆盖验收未因此自动通过。
4. **修正后动态回归与突变**：Icarus 下120个派生探针通过，八个注入缺陷全部被断言捕获。记录新源码绑定、testbench SHA、每个实验耗时。此前5.050结果保留，修正前后Icarus正常版本输出摘要一致。
   - 证据：`8-本轮实验/GPU适配器突变-20261107/completion.json`。
   - 探针覆盖两memory端口、host响应保持、sticky故障、忙启动、复位后冲刷与重发。背压为按seed派生的固定延迟，不能称为原始整机概率背压生成器复现。
