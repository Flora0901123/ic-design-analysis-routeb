# 全100案例 CPU RTL / GPU SimX 本机复跑结果

日期：2026-11-04。冻结案例 P1 33 个、P2 34 个、P3 33 个；每例 seed 1–10，各平台实际执行 1000 条。使用 baseline 算子；复用经过哈希检查的编译产物，执行日志为本轮新生成。

| 平台 | 执行条数 | 数值/状态匹配 | 数值失败 | 不支持 | 完整匹配案例 |
|---|---:|---:|---:|---:|---:|
| VexRiscv RTL | 1000 | 1000 | 0 | 0 | 100/100 |
| Vortex SimX | 1000 | 970 | 0 | 30 | 97/100 |

两端可比较的 970 条，其状态、BF16 输出、primitive 以及 P1 selected 逐项一致。

GPU 尚未通过的三个案例：P1-MINI-30、P2-MINI-30、P3-MINI-30，均为 dma-error，各 10 个 seed。实际返回 UNSUPPORTED_BUS_INJECTION，不伪造为 BUS_ERROR 或 PASS。需要另外运行 DMA 错误注入适配器 RTL 测试。

CPU 的1000条数值/状态匹配不等于完整协议验收；CPU/GPU 的适配器协议、资源及正式晋升门槛仍独立验收。SimX 只用于功能正确性，不提供 GPU 硬件性能计分数据。

本轮 CPU 首次尝试遇到 WSL 文件读取错误并停止，改为管道接收日志后完整重跑成功；原始失败记录保留。GPU 出现一次长命令等待提示，之后自行完成，无需分批或中断。
