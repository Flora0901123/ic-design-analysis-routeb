# 工程生产流程全景图说明

## 使用

- 悬停或键盘聚焦模块：高亮全部后续关联及连线；非关联模块淡化。
- 点击模块：锁定详情，可查看范围、局限、计时和原始证据。再次点击或按Esc、点击“回到全景”可取消锁定。
- “原尺寸查看 / 适合窗口”切换横向浏览与全景。小屏默认原尺寸，可横向滚动。
- 证据链接相对交付包根目录，分享时应连同工作包交付，单独复制HTML仍可看图但证据链接会失效。
- 页面提供打印入口。优先使用横向纸张；交互以HTML为准。
